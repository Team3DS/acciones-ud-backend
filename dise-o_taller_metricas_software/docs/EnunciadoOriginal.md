# **Taller Métricas de Software**

El propósito de este taller es dar las pautas para la aplicación de **los conceptos de calidad**, para esto, se va a tratar de aproximar a los conceptos de métricas y estimación de software, de lo cual, es necesario conformar grupos de *tres (3) personas*. Luego de realizar la conformación de grupos. se debe realizar una aplicación con todas la funcionalidades CRUD para la gestión de una empresa especialista en la **preparación de comidas rápidas.** La aplicación necesita almacenar información sobre las *comidas rápidas* y *los clientes* que tienen en una base de datos y realizar operaciones como **agregar, actualizar, eliminar y obtener clientes y productos de comidas rápidas**. Para mantener el código organizado y seguir los principios de la POO, cada grupo debe ajustar los productos y las características a implementar.

Después de realizar la aplicación, se requiere instalar la herramienta de software llamada **Source Monitor**, de manera intuitiva haga la carga del código fuente y aplique la métricas que tiene la herramienta.

Consigne en un documento los resultados obtenidos, analice que tipo de métricas maneja dicha herramienta y haga un interpretación de los resultados obtenidos de su aplicación.

Entregables:

- Código fuente de la aplicación (JAVA)
- Diagrama de clases de la aplicación
- Diagrama de casos de uso de la aplicación
- Documento con los resultados y la interpretación de los mismos.
