# Aclaración de requerimientos

Se realiza una serie de consultas al cliente frente a varios tópicos, entre ellos:

- ¿Qué considera la tienda como cliente?
- El frente de gestión de comida rápida, ¿está más relacionado con inventario o con generación del menú?

## Inventario

- **Cliente:** puede ser una empresa o un surtidor.
- **Datos requeridos:** nombre, cédula y correo electrónico.
- **Histórico de compras:** se debe llevar registro del histórico de compras del cliente.

## Source Monitor

- Permite generar diagramas de **kiviat**.
- Permite sacar métricas de una clase o de todo el proyecto.
